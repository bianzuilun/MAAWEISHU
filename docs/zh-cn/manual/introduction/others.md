## GPU 加速推理

使用 DirectML 调用 GPU 进行识别推理加速<sup>[PR](https://github.com/MaaAssistantArknights/MaaAssistantArknights/pull/9236)</sup>，可通过少量的 GPU 占用降低大量的 CPU 占用，推荐启用。

经测试，部分显卡因缺少功能或性能较低，在使用本功能时会出现识别问题。MAA 已内置了部分 GPU 黑名单<sup>[PR1](https://github.com/MaaAssistantArknights/MaaAssistantArknights/pull/9990)[PR2](https://github.com/MaaAssistantArknights/MaaAssistantArknights/pull/12134)</sup>，若列表外的显卡在启用本功能后也出现识别问题，请发 Issue。

## 仅一次

主界面和设置中的配置更改通常会自动保存，但以下几种会在 MAA 重启后重置。

- 标有 `*` 号的选项
- 标有 `（仅一次）` 的选项
- 通过右键单击复选框得到的半选开关

许多复选框支持右键单击进行半选（仅一次生效），MAA 重启后重置。常见的应用场景包括：

- **主任务列表**：右键勾选某个任务为半选状态，本次运行会执行该任务，但重启后恢复原状。默认右键为 ｢仅一次生效｣ ，可在 `设置` - `界面设置` - `反转主任务右键单击效果` 中切换为 ｢仅一次跳过｣ （即右键半选的任务本次不执行）。
- **战斗设置**：`使用药剂`、`使用源石` 等选项右键半选后仅本次生效。

## 启动时自动切换配置

MAA 支持通过启动参数自动切换配置，在 MAA 进程名后附加 `--config <配置名>` 即可。例子：`./MAA/MAA.exe --config 官服`。

部分符号需要转义，参考 Json。例子：在配置名为 `"官服"` 时，参数应为 `--config \"官服\"`。

## 开始前/结束后脚本

v4.13.0 后支持设置开始前/结束后脚本，可在任务前后自动执行批处理文件。输入框内需填写批处理文件即 `*.bat` 的绝对或相对路径。

## 配置迁移

在 Windows 版本中，MAA 的所有配置都存放在 `config` 文件夹里。迁移此文件夹即可迁移 MAA 的所有设置。

## 定时执行

在 `设置` - `定时执行` 中可设置最多 8 组定时任务。每组包含启用开关、时间（时:分）和对应的配置。

- 定时时间到达后，MAA 会自动连接模拟器并开始执行当前配置中勾选的任务。
- 每个定时项的复选框支持右键半选（仅一次），即只在本次生效，MAA 重启后重置。

### 强制定时启动

勾选后会**停止当前正在运行的任务**，重启游戏并开始新任务。适用于应对游戏每日 04:00（服务器当地时间）的闪断更新——在闪断时间后强制重启游戏并重新执行任务，确保任务不会因闪断而卡住。

游戏掉线或闪断后，MAA 会停止任务，不会自动重连。通宵挂机时，请同时启用 `开始唤醒` 任务，并将定时时间设置在每日 4:10 之后（闪断更新窗口通常为 4:00-4:10）。

### 自定义配置选择

勾选后，每个定时项可以指定不同的配置。MAA 会在定时触发**前两分钟**重启并切换到对应配置，再开始执行任务。

## 更新

MAA 的更新分为两种内容：

- **软件版本**：主程序的界面和功能更新。
- **资源版本**：素材数据更新，包含新关卡地图、掉落物图标、公招干员标签等。软件版本发布时通常已包含当时的最新资源。

::: tip 导航热更
另有一种 ｢导航热更｣ ，会自动触发，用于更新主界面提示与活动关卡入口。成功后右上角会显示提示。
:::

### 版本类型

GitHub Releases 会发布三类版本：

- **正式版**：Bug 更少，新功能新主题支持更慢。新功能可能需要数周后才会支持。
- **公测版**：可能存在少量 Bug，新功能新主题支持更快。
- **内测版**：包含不稳定功能，仅供测试。请勿在其他地方讨论内测版问题。

::: tip
若界面提示版本过低且最低需求版本为公测版，说明该功能目前仅在公测版中提供，需等待正式版发布或改用公测版完整包。
:::

### 获取新版本

MAA 不再提供应用内自动更新。请从 [GitHub Releases](https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases) 下载完整安装包（`MAA-<版本号>-win-<架构>.zip`，如 `MAA-v5.20.0-win-x64.zip`），解压到**新**文件夹后，将旧目录的 `config`、`data` 与 `debug` 文件夹复制过去以保留配置和日志（`cache` 与 `achievement` 可选）。⚠️ 请勿直接覆盖旧文件夹。

资源文件随完整安装包一同发布；也可从 [MaaResource](https://github.com/MaaAssistantArknights/MaaResource/archive/refs/heads/main.zip) 下载后覆盖 `resource` 文件夹（增量内容，请勿删除原文件夹）。

## 其他说明

- 首页左侧任务可以拖动改变顺序，基建换班设置中设施顺序同理。
- 所有点击操作，都是点击按钮内随机位置，并模拟正态分布（按钮中心的点击概率最高，距离中心越远，点击概率越低）。
- 底层算法纯 C++ 开发，并设计了多重缓存技术，最大限度降低 CPU 和内存占用。
- 推荐非杠精的同学使用公测版，一般来说更新快且 bug 少。（什么 MIUI (╯‵□′)╯︵┻━┻
